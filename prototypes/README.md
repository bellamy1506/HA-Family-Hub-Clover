# Prototypes

Throwaway pages that answered a design question, kept so a part someone liked can be pulled back later (owner, 2026-10-30). None of this is served by Home Assistant or installed by HACS; only `custom_components/` is. Data is always made up: this repo is public.

Each prototype gets a folder with its page, a README (the question, every variant tried, what was picked and why, the reviews) and a `shots/` folder of pictures, so what was tried can be seen without running anything. When a prototype changes after review, the earlier round's pictures stay.
